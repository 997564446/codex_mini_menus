# 真机验收清单

准备三个微信账号：厨师、普通食客、等待审批食客。每项完成后在真机或体验版打勾。

- [ ] 错误初始化口令无法认领；两台设备同时认领时只有一台成功。
- [ ] 厨师生成邀请码、分享入口和小程序码，旧邀请码刷新后立即失效。
- [ ] 新食客提交申请前看不到菜单；厨师通过后可进入，拒绝后可用新邀请码重试。
- [ ] 厨师可新建、修改和删除分类；删除后原分类菜品自动移入“未分类”。
- [ ] 自定义分类可上下拖动排序；“主食”固定在“未分类”上方，“未分类”始终位于最下方。
- [ ] 自定义分类的“···”只在小范围内响应，点击分类主体只切换分类。
- [ ] 菜品库左侧选择分类、右侧仅显示当前分类和“未分类”的菜品，当前分类排在前面；其他已归类菜品不出现。
- [ ] 菜品库右侧可批量勾选菜品；保存后勾选菜品进入当前分类，取消勾选的原分类菜品回到“未分类”。
- [ ] 部署 `1.2.2-5` 后首次进入菜品库，自动按 `初始化菜品.txt` 重新初始化 71 道默认菜品，单价、有限/无限库存与清单一致，全部位于“未分类”。
- [ ] 厨师手动添加菜品时，菜品名称、有限库存数量和单价任一未填写都不能保存；选择无限库存时无需填写数量。
- [ ] 手动添加的单价最多两位小数，保存后点餐页和订单金额显示正确。
- [ ] 厨师只能在“未分类”新增或删除菜品；完成 `1.2.2-5` 初始化后再删除的预置菜品不会被自动重新添加，历史订单不受影响。
- [ ] 库存设置页明确显示“有限库存”和“无限库存”两个选项。
- [ ] 厨师可分别打开周一至周日的编辑页，通过下拉框切换早餐、中餐和晚餐；编辑页左侧选择分类，右侧显示该分类菜品，并可全选或取消全选当前分类。
- [ ] 任意菜品都可加入厨师选择的任意一天；切换分类时，其他分类已勾选的菜品不会丢失。
- [ ] 库存为 0 的菜品不可选择；有限库存下单扣减、改单按差额调整、取消后归还；无限库存不扣减。
- [ ] 食客可选择菜品份数、填写菜品备注及整单备注并提交。
- [ ] “主食”分类包含置顶、无限库存、价格为 0 的“不要主食”；新建三餐菜单默认勾选该菜品，菜单编辑页不显示“未分类”。
- [ ] 食客点餐页按分类双列展示；没有入选菜品的分类不显示，库存为 0 的菜品沉底、置灰且不可选择。
- [ ] 食客每餐必须选择至少一种主食；选择“不要主食”时出现“不吃主食会低血糖的噢。”确认提示。
- [ ] 连续点击提交不会产生重复订单；同一食客每天早餐、中餐、晚餐各自最多一张订单，待确认且未截止时可以加菜。
- [ ] 食客最多提前 2 天下单；早餐 9 点、中餐 14 点、晚餐 21 点后服务端拒绝新下单和加菜。
- [ ] 提前一天或两天下单时不即时打扰厨师，并在用餐当天早餐 6 点、中餐 10 点、晚餐 17 点产生一次防重提醒。
- [ ] 待确认订单可修改和取消；厨师确认后不可修改或取消。
- [ ] 厨师看板正确汇总人数、份数、规格和备注，可逐单或按当天菜单推进状态。
- [ ] 厨师取消已确认订单时必须填写原因，食客能查看该原因。
- [ ] 本周已过去的日期不能新下单，但历史订单仍可查看。
- [ ] 停用成员不能进入业务页，恢复后可继续使用。
- [ ] 新订单始终产生站内通知；订阅消息失败时订单仍创建成功。
- [ ] 菜品分类、库存或星期菜单变化后，历史订单仍展示原下单快照。
