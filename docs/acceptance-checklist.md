# 真机验收清单

准备三个微信账号：厨师、普通食客、等待审批食客。每项完成后在真机或体验版打勾。

- [ ] 错误初始化口令无法认领；两台设备同时认领时只有一台成功。
- [ ] 厨师生成邀请码、分享入口和小程序码，旧邀请码刷新后立即失效。
- [ ] 新食客提交申请前看不到菜单；厨师通过后可进入，拒绝后可用新邀请码重试。
- [ ] 厨师可新建、修改和删除分类；删除后原分类菜品自动移入“未分类”。
- [ ] 厨师可新建菜品、单选/多选规格，并上传菜品图。
- [ ] 厨师可按日期和早餐/午餐/晚餐排菜，手动开放与关闭。
- [ ] 食客可选择份数和规格、填写菜品备注及整单备注并提交。
- [ ] 连续点击提交不会产生重复订单；同一食客同餐次只有一张订单。
- [ ] 待确认订单可修改和取消；厨师确认后不可修改或取消。
- [ ] 厨师看板正确汇总人数、份数、规格和备注，可逐单或按餐次推进状态。
- [ ] 厨师取消已确认订单时必须填写原因，食客能查看该原因。
- [ ] 关闭菜单后不能新下单或改单，但历史订单仍可查看。
- [ ] 停用成员不能进入业务页，恢复后可继续使用。
- [ ] 新订单始终产生站内通知；订阅消息失败时订单仍创建成功。
- [ ] 菜品改价、改规格或下架后，历史订单仍展示原快照。
