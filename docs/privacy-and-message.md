# 隐私与订阅消息配置

## 隐私保护指引

小程序仅使用微信云函数上下文提供的用户标识，并收集用户主动填写的家中称呼、家庭关系、点餐内容与备注。当前版本不读取手机号、定位、通讯录，也不强制获取微信头像和昵称。

在微信公众平台填写《用户隐私保护指引》时应列出：

- 家中称呼与家庭关系：用于厨师识别家庭成员；
- 点餐内容与备注：用于家庭备餐和订单状态反馈；
- 用户标识：用于登录、家庭隔离和权限判断；
- 相册：仅厨师主动保存邀请码图片时触发系统授权。

代码会在调用相册或相机前执行 `wx.requirePrivacyAuthorize`。如果公众平台尚未完成隐私保护指引配置，相关操作会被微信拒绝，但不会影响菜单文字、审批和订单主流程。

## 新订单订阅消息

当前使用一次性订阅模板 `预约通知`（模板编号 461），字段如下：

- `name1`：点餐人；
- `date3`：用餐日期；
- `thing13`：预约项目（对应星期菜单点餐）；
- `character_string54`：订单编号；
- `thing7`：菜品总份数备注。

将同一模板 ID 同时填写到：

1. `miniprogram/config/env.js` 的 `chefOrderTemplateId`；
2. 云数据库 `system_config/global` 的 `chefOrderTemplateId`。

厨师每次在“家庭 → 微信提醒”主动授权后可接收一次消息。发送失败只写入 `notification_logs`，不会回滚订单；站内通知始终保留。
